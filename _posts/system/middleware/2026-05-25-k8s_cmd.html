Maintenance

disable schedule

// disable
kubectl cordon mynode
kubectl taint node mynode maintenance=offline:NoSchedule
// recover
kubectl taint node mynode maintenance=offline:NoSchedule-
kubectl uncordon mynode

delete node

kubectl drain mynode --ignore-daemonsets --delete-emptydir-data [--timeout=300s]
	kubectl get pods -A --field-selector spec.nodeName=mynode
kubectl delete node mynode


Utility

check usage

kubectl top nodes
kubectl top pods --all-namespaces

debug pod inside

kubectl exec -it my-pod -- /bin/bash

data transfer

  • port-forward
    • kubectl port-forward -n dev pod/nginx --address 0.0.0.0 8080:80
  • Node port
    • kubectl expose pod nginx -n dev --type=NodePort --port=88 --target-port=88 --name=nginx-service
