GIC-400

Distributor

  1. Detect interrupts
  2. Forward them to the CPU interfaces

CPU interface

  1. Perform priority masking and preemption handling of physical interrupts
  2. Signal them to the corresponding processor
  3. ---> ( The processor reads the interrupt ID. )
  4. Receive acknowledge from the processor
  5. ---> ( The processor handles the interrupt. )
  6. Receive End of Interrupt (EOI) from the processor
