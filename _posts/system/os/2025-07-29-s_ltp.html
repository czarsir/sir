Directory Structure

  • testcases (every single test case)
    • open_posix_testsuite
    • realtime
  • runtest (test suite. Each file contains a list of test cases.)
    • syscalls
  • scenario_groups (a set of runtest files)
    • default
  • output (item fail/success)
  • results (summary)

Example

run the test suite of all syscalls

./runltp -f syscalls
