Dependency Management

"rosdep" reads package.xml for "rosdep keys".

base operation

rosdep init
rosdep update
rosdep install --from-paths my_src_path --ignore-src -y

check "rosdep keys"

rosdep resolve key_to_check

handle unknown keys

  • (recommended) skip and manually install them later.
    • rosdep install --from-paths src --ignore-src -y --skip-keys "unknown_key1 unknown_key2"
  • (optional) add them to rosdistro index (local cache path: ~/.ros/rosdep)
    • (add item in /etc/ros/rosdep/sources.list.d/20-default.list)
    rosdep update


Build the Workspace

directory structure

.
├── build
├── install
├── log
└── src

build

colcon build --symlink-install

tips

  • build a specific package
    • colcon build --packages-select [package]
  • build a specific package with dependency
    • colcon build --packages-up-to [package]
  • build a specific package with CMake args
    • colcon build --packages-select [package] --cmake-args -DCMAKE_BUILD_TYPE=Debug
  • build a specific package with Makefile flags (single thread in case of kernel OOM)
    • MAKEFLAGS=-j1 colcon build --packages-select [package]
  • skip a specific package (in the directory of the package)
    • touch COLCON_IGNORE


Usage

Source the environment

source install/setup.bash
