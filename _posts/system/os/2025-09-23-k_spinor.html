Specification

JEDEC

Mode

Mode Instruction Address Data
1-1-1 1S 1S 1S
4-4-4 4S 4S 4S
8-8-8 8S 8S 8S
8-8-8 DTR 8D 8D 8D
(refer to Communication - SPI for more)
S: SDR (Single Data Rate)
D: DDR (Dual Data Rate)
DTR: Double Transfer Rate


Hardware

  • Host ---> spiNor : clock
  • Host ---> spiNor : chip select (CS)
  • Host <-> spiNor : data[0-7]
  • (Following can utilize GPIO)
  • Host ---> spiNor : reset


Workflow

  1. reset host
  2. reset spiNor
  3. cmd enable reset: 0x66
  4. cmd reset: 0x99
  5. cmd read ID: 0x9F
  6. cmd read status: 0x5
    7. (optional: change mode)
  7. cmd read bytes: 0x3
  8. cmd enable write: 0x6
  9. cmd erase block
  10. cmd enable write: 0x6
  11. cmd page program
